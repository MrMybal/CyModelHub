# CyModelHub service operations

Generated by `scripts/make_api_doc.py` from the running service. Do not edit by hand.

Every operation is available in three ways, with the same name and arguments:

| From | Call |
| --- | --- |
| C++ | `cymodelhub::Client::invoke("models_list", {{"type", "lora"}})` |
| HTTP | `POST <url>/v1` with `{"method":"invoke","name":"models_list","arguments":{"type":"lora"}}` |
| MCP | the tool `models_list`, over `<url>/mcp` or through `CyModelHubMcp` (stdio) |

`<url>` and the access token are in `service.json`, in the CyModelHub data folder
(`%LOCALAPPDATA%\CyModelHub` on Windows, `~/.local/share/cymodelhub` on Linux,
`~/Library/Application Support/CyModelHub` on macOS). HTTP requests carry
`Authorization: Bearer <token>` and `Content-Type: application/json`; the service listens on
the loopback interface only. A failure is `{"error":{"code":"...","message":"..."}}` with
HTTP 400 or 403; the C++ client throws `cymodelhub::Error` with the same code.

Operations marked *job* return `{"job":"<id>"}` at once; follow it with `jobs_get`
(`Client::wait_job`). Operations marked *read* change nothing.

## hub_shutdown

Stop the CyModelHub service. Applications start it again when they need it.

No arguments.

## hub_status

CyModelHub service status: version, data folder, model count, running jobs. The revision number grows whenever the catalogue changes.

No arguments.

## install_start

Download a model into a registered location and add it to the catalogue. Give either a direct HTTPS url, or a Hugging Face repository and file. Runs as a job with progress; an interrupted download resumes. The SHA-256 is verified when it is known.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `destination` | string |  | Absolute path of the folder, inside a registered location. Default: CyModelHub's own store. |
| `file` | string |  | File inside the repository, e.g. model.Q4_K_M.gguf. |
| `filename` | string |  | Name to save as. Default: the name in the address. |
| `repository` | string |  | Hugging Face repository, e.g. org/name. |
| `revision` | string |  | Branch, tag or commit. Default: main. |
| `sha256` | string |  | Expected SHA-256, 64 hex digits. |
| `token` | string |  | Access token for gated downloads. It is sent only to the site of the address and is not stored. |
| `url` | string |  | Direct https:// address of the model file (http:// is accepted for this computer only). |

## models_hash

Compute the SHA-256 of a model file as a job. The hash identifies the exact file on Hugging Face or Civitai and proves that two copies are identical.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `id` | string | required | Model ID, as returned by models_list or models_resolve. |

## models_link

Make an installed model visible inside another application's folder without copying it: a hard link (same drive, no extra space) or a symbolic link.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `destination` | string | required | Absolute path of the folder that receives the link, inside a registered location. |
| `id` | string | required | Model ID, as returned by models_list or models_resolve. |
| `mode` | `hard` \| `symbolic` |  | Default: hard for a file, symbolic for a folder. |

## models_list

List the AI models installed on this computer and shared between applications (LLM, diffusion, video, audio, LoRA, VAE...). Filter by words, type, modality, format, architecture or source. Each model has an ID and an absolute path.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `architecture` | string |  | Model family, e.g. llama, qwen2, sdxl, sd15, flux, wan, whisper. |
| `descending` | boolean |  | Reverse the sort order. |
| `favorite` | boolean |  | Only favourites (true) or only non-favourites (false). |
| `format` | string |  | Storage format: gguf, safetensors, pickle, onnx, diffusers, transformers, mlx... |
| `limit` | integer |  | Page size. Default: 100. |
| `missing` | boolean |  | Only entries whose file disappeared (true) or only present ones (false). |
| `modality` | string |  | Domain: text (LLM), image, video, audio, embedding, multimodal, 3d, other. |
| `offset` | integer |  | First result to return. |
| `query` | string |  | Words that must all appear in the name, path, repository, architecture or tags. |
| `root` | string |  | ID of a watched location (see roots_list). |
| `sort` | `name` \| `size` \| `modified` \| `added` \| `type` |  | Sort key. Default: name. |
| `source` | string |  | Where it was found: huggingface, ollama, lmstudio, managed, folder, manual. |
| `tag` | string |  | A user tag. |
| `type` | string |  | Role: model, lora, vae, controlnet, text_encoder, vision_encoder, embedding, upscaler, adapter, projector, other. |

## models_move

Move a model file or folder to another registered location, for example a larger drive. Runs as a job (see jobs_get). Models owned by Hugging Face or Ollama stay where those tools expect them.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `destination` | string | required | Absolute path of the destination folder, inside a registered location. |
| `id` | string | required | Model ID, as returned by models_list or models_resolve. |
| `leaveLink` | boolean |  | Leave a symbolic link at the old place so other applications still find the model. |

## models_remove

Forget a model: its entry leaves the catalogue. The file itself is never deleted; a later scan lists it again if it is in a watched location.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `id` | string | required | Model ID, as returned by models_list or models_resolve. |

## models_resolve

Find where a model is installed. Give a name, a file name, a repository (org/name), a SHA-256 or an ID; the best installed match is returned with its absolute path, so an application can load it instead of downloading it again.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `format` | string |  | Storage format: gguf, safetensors, pickle, onnx, diffusers, transformers, mlx... |
| `modality` | string |  | Domain: text (LLM), image, video, audio, embedding, multimodal, 3d, other. |
| `query` | string | required | Name, file name, repository, SHA-256 or ID. |
| `type` | string |  | Role: model, lora, vae, controlnet, text_encoder, vision_encoder, embedding, upscaler, adapter, projector, other. |

## models_update

Edit how a model is classified and annotated. A field set here is kept by later scans; list a field in `reset` to return it to automatic detection.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `architecture` | string |  | Model family, e.g. llama, qwen2, sdxl, sd15, flux, wan, whisper. |
| `favorite` | boolean |  | Mark or unmark as favourite. |
| `id` | string | required | Model ID, as returned by models_list or models_resolve. |
| `modality` | string |  | Domain: text (LLM), image, video, audio, embedding, multimodal, 3d, other. |
| `name` | string |  | Display name. |
| `notes` | string |  | Free text. An empty string clears it. |
| `reset` | array of `name` \| `type` \| `modality` \| `architecture` |  | Fields to detect automatically again. |
| `tags` | array of string |  | Replaces the tag list. |
| `type` | string |  | Role: model, lora, vae, controlnet, text_encoder, vision_encoder, embedding, upscaler, adapter, projector, other. |

## roots_add

Watch a folder for models, for example the models folder of ComfyUI or a drive dedicated to models, and scan it.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `label` | string |  | Name shown for this location. |
| `path` | string | required | Absolute path of an existing folder. |
| `recursive` | boolean |  | Also look in sub-folders. Default: true. |

## roots_enable

Switch a location on or off. Switching one off forgets the models found in it; switching it on scans it again.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `enabled` | boolean | required | New state. |
| `id` | string | required | Location ID. |

## roots_list

List the locations where models are looked for: the stores of Hugging Face, Ollama and LM Studio when present, CyModelHub's own store, and the folders added by the user.

No arguments.

## roots_remove

Stop watching a folder added by the user and forget the models found in it. No file is deleted.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `id` | string | required | Location ID. |

## scan_start

Look for models again in one location, or in all of them. Runs as a job; unchanged files are not read again.

| Argument | Type | | Description |
| --- | --- | --- | --- |
| `root` | string |  | Location ID. Omit to scan everything. |
